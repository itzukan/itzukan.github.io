CPU・メモリ・ストレージの違い

パソコンで写真を開いて明るさを変えます。編集途中の写真と、保存した写真はどこにあるでしょうか。

🖼️ 写真を開く → 編集する → 保存する

  1. 🗂️
    ① 開くストレージ → メモリ
    保存された写真を読み込む
  2. ⚙️
    ② 編集するCPUがメモリ上の写真データを処理
    明るさを変えるための計算をする
  3. 💾
    ③ 保存するメモリ → ストレージ
    編集した内容を書き込む

電源を切っても残るのは？

  • 📋メモリ（RAM・主記憶）作業中のデータを置く場所。電源を切ると内容が消える。
  • 🗂️ストレージ（SSDなど・補助記憶）保存したファイルを置く場所。電源を切っても残る。
