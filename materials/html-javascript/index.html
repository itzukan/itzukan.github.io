STEP 1｜index.htmlを作る

下のコードをすべてコピーして新規保存しよう。

⌨️ やってみる

index.html（コピー可能）

コードをすべてコピーし、デスクトップ / IT図鑑ストアに index.html として保存します。末尾に .txt を付けないでください。

📄 index.html
<!doctype html>
<html lang="ja">
<head>
<meta charset="utf-8">
<title>IT図鑑ストア</title>
</head>
<body>
<h1>IT図鑑ストア</h1>
<p>はじめてのWebページ！</p>
</body>
</html>

📁 編集するファイル：デスクトップ → IT図鑑ストア → index.html

function showMessage() {
 document.getElementById("message")
 .textContent = "押せました！";
}
</script>

完成版の仕組みを読む

個数と合計金額を更新する。

HTML商品カードと「＋」「−」ボタン
CSS2列の商品配置と色・余白
JavaScript個数を更新 → (りんご＋みかん) × 150円

完成版ZIPの step05/index.html では、changeApple(1)、changeOrange(-1)、resetCart() が画面を更新します。

💡 理解する

HTML・CSS・JavaScriptの担当

HTML：商品カードと個数ボタン。CSS：商品カードの配置や色。JavaScript：個数の変更と合計金額の計算。

💡 理解する

関数の例

changeApple(1)：りんごを1個増やす。changeOrange(-1)：みかんを1個減らす。resetCart()：個数を0に戻す。
