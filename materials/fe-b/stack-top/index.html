スタックを配列と top で管理する

追加と取り出しのたびに、スタックの先頭側の境界を top で管理します。

📚 top が指すのは、最後に入れた有効な値

この例では、要素番号1から top までをスタックの有効範囲として使います。

変数の値の変化
実行した処理top有効な値result
初期値2{4, 7}—
7を読む2{4, 7}7
top を減らす1{4}7
top を増やす2{4} ＋ 書き込み待ち7
位置2に9を書く2{4, 9}7
9を足す2{4, 9}16
top を減らす1{4}16

top を戻すだけで取り出しを表現でき、配列の古い値を0にする必要はありません。

確認問題

配列 stack の要素番号は1から始まります。処理後の result はいくつですか？ 
整数型の配列: stack ← {4, 7, 0}
整数型: top ← 2
整数型: result

result ← stack[top]
top ← top - 1
top ← top + 1
stack[top] ← 9
result ← result + stack[top]
top ← top - 1
