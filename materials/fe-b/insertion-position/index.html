基本情報技術者試験・科目B

整列済みの部分に1つ挿入する

挿入する値より大きな要素だけを右にずらし、空いた位置に値を入れます。

📥 先に値を退避して、挿入位置を作る

key は3のままです。pos は次に key を置ける位置です。

変数の値の変化
処理posdata
初期値4{2, 5, 8, 3}
j = 3：8を移す3{2, 5, 8, 8}
j = 2：5を移す2{2, 5, 5, 8}
j = 1：2はそのまま2{2, 5, 5, 8}
key の3を入れる2{2, 3, 5, 8}

途中で同じ値が並んでも、最後の代入で空いた位置を埋めます。

確認問題

配列 data の要素番号は1から始まります。処理後の data はどうなりますか？ 
整数型の配列: data ← {2, 5, 8, 3}
整数型: key ← data[4], pos ← 4, j

for (j を 3 から 1 まで 1 ずつ減らす)
  if (data[j] ＞ key)
    data[j + 1] ← data[j]
    pos ← j
  endif
endfor
data[pos] ← key
