最初に一致する位置を記録する

同じ値が複数あっても、最初に見つけた要素番号だけを残します。

🔎 位置を見つけたら保持する

position が0のときは「まだ見つけていない」という意味です。

変数の値の変化
idata[i]処理後の position
初期値—0
140
282
362

i = 4 でも値は8ですが、既に position が2のため条件全体は偽です。

確認問題

配列 data の要素番号は1から始まります。処理後の position はいくつですか？ 
整数型の配列: data ← {4, 8, 6, 8}
整数型: i, position ← 0

for (i を 1 から 4 まで 1 ずつ増やす)
  if (position = 0 and data[i] = 8)
    position ← i
  endif
endfor
