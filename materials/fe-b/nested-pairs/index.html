二重ループで条件に合う組を数える

外側の要素を1つ選ぶたびに、内側の配列を最初から調べます。

🔄 i が変わると j は1に戻る

同じ i の行をまとめて見ると、内側のループを1周したことが分かります。

変数の値の変化
ij要素の和処理後の count
初期値——0
112＋3＝50
122＋5＝71
132＋1＝31
214＋3＝72
224＋5＝92
234＋1＝52

比較は2×3＝6回です。そのうち条件に合うのは2回です。

確認問題

配列 left と right の要素番号は1から始まります。処理後の count はいくつですか？ 
整数型の配列: left ← {2, 4}
整数型の配列: right ← {3, 5, 1}
整数型: i, j, count ← 0

for (i を 1 から 2 まで 1 ずつ増やす)
  for (j を 1 から 3 まで 1 ずつ増やす)
    if (left[i] + right[j] = 7)
      count ← count + 1
    endif
  endfor
endfor
