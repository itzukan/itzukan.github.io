バブルソートの1周で値がどう動くか追う

隣り合う値を比較し、順番が逆なら交換します。左から1周した直後の状態を見ます。

🫧 大きい値が右へ1つずつ移る

左の値が右の値より大きいときだけ、temp に退避して交換します。

変数の値の変化
i比べた値temp交換後の data
初期値——{5, 2, 4, 1}
15 と 25{2, 5, 4, 1}
25 と 45{2, 4, 5, 1}
35 と 15{2, 4, 1, 5}

1周で最大の5は末尾に着きますが、他の要素はまだ昇順とは限りません。

確認問題

配列 data の要素番号は1から始まります。次のループを1周分実行したあと、data はどうなりますか？ 
整数型の配列: data ← {5, 2, 4, 1}
整数型: i, temp

for (i を 1 から 3 まで 1 ずつ増やす)
  if (data[i] ＞ data[i + 1])
    temp ← data[i]
    data[i] ← data[i + 1]
    data[i + 1] ← temp
  endif
endfor
