二次元配列で行と列を入れ替える

元の表の行番号と列番号を逆にして、新しい表のどこに書くかを決めます。

🔁 a[row, col] を b[col, row] へ移す

元は2行3列、新しい表は3行2列です。

変数の値の変化
rowcol書き込み先入れた値
11b[1, 1]2
12b[2, 1]4
13b[3, 1]5
21b[1, 2]1
22b[2, 2]7
23b[3, 2]4
終了後—result9

最後は b の3行目に移った5と4を足して9です。

確認問題

配列 a と b の行・列番号は1から始まります。処理後の result はいくつですか？ 
整数型の二次元配列: a ← {{2, 4, 5}, {1, 7, 4}}
整数型の二次元配列: b ← {{0, 0}, {0, 0}, {0, 0}}
整数型: row, col, result

for (row を 1 から 2 まで 1 ずつ増やす)
  for (col を 1 から 3 まで 1 ずつ増やす)
    b[col, row] ← a[row, col]
  endfor
endfor
result ← b[3, 1] + b[3, 2]
