循環キューで末尾から先頭へ戻る

配列に並べたキューを読み、末尾の次は要素番号1へ戻ります。

🔄 front は4の次に1へ戻る

front は次に取り出す要素番号です。

変数の値の変化
i読んだ位置次の frontout
初期値—3{0, 0, 0}
134{4, 0, 0}
241{4, 6, 0}
312{4, 6, 8}

位置4の次は余り0に1を足して位置1になります。

確認問題

配列 queue の要素番号は1から始まり、取り出せる要素が3つあります。処理後の out はどうなりますか？ 
整数型の配列: queue ← {8, 0, 4, 6}
整数型の配列: out ← {0, 0, 0}
整数型: front ← 3, i

for (i を 1 から 3 まで 1 ずつ増やす)
  out[i] ← queue[front]
  front ← (front ÷ 4) の余り + 1
endfor
