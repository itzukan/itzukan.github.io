基本情報技術者試験・科目B

二次元配列で行ごとの合計を求める

行ごとに合計を0から計算し、結果を別の配列に保存します。

🧮 次の行に移ったら sum を0に戻す

内側のループは列を進み、外側のループは行を進みます。

変数の値の変化
実行した処理sumout
1行目を開始0{0, 0}
1行1列：2を足す2{0, 0}
1行2列：4を足す6{0, 0}
1行目を保存6{6, 0}
2行目を開始0{6, 0}
2行1列：1を足す1{6, 0}
2行2列：7を足す8{6, 0}
2行目を保存8{6, 8}

sum の初期化が外側のループの中にあるため、1行目の合計は2行目に持ち越されません。

確認問題

table は行と列がそれぞれ1から始まる二次元配列です。out の要素番号も1から始まります。処理後の out はどうなりますか？ 
整数型の二次元配列: table ← {{2, 4}, {1, 7}}
整数型の配列: out ← {0, 0}
整数型: row, col, sum

for (row を 1 から 2 まで 1 ずつ増やす)
  sum ← 0
  for (col を 1 から 2 まで 1 ずつ増やす)
    sum ← sum + table[row, col]
  endfor
  out[row] ← sum
endfor
