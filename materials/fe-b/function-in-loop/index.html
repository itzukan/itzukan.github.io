確認問題

次のコードでは score 関数を呼び出します。配列 data の要素番号は1から始まります。処理後の total はいくつですか？ 
○整数型: score(整数型: x)
  if (x ≧ 5)
    return 2
  endif
  return 1

整数型の配列: data ← {2, 8, 5}
整数型: i, total ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  total ← total + score(data[i])
endfor
