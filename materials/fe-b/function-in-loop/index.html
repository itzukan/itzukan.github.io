ループの中で関数の戻り値を足す

要素を関数に渡す処理と、戻り値を合計する処理を分けて追います。

↩️ 呼び出しごとに戻り値を取り出す

各周回で関数に渡した値と、足した値を並べています。

5ちょうどでも条件 x ≧ 5 は真なので、戻り値は2です。

確認問題

次のコードでは score 関数を呼び出します。配列 data の要素番号は1から始まります。処理後の total はいくつですか？ 
○整数型: score(整数型: x)
  if (x ≧ 5)
    return 2
  endif
  return 1

整数型の配列: data ← {2, 8, 5}
整数型: i, total ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  total ← total + score(data[i])
endfor

  • 関数の引数と戻り値を追う 同じ関数でも、呼び出すたびに受け取る値が変われば、通る分岐も変わります。
  • 再帰の呼び出しと戻り値を追う 自分と同じ処理に小さい値を渡し、停止条件に着いてから結果が戻る順番を追います。
  • 値を半分にしながら終了条件を追う 整数を半分にする処理を、条件が偽になるまで繰り返します。
