最小の要素を見つけて先頭と交換する

まず最小値がある場所を調べ、最後に1回だけ先頭と交換します。

📍 探している間は配列を書き換えない

pos で場所を覚え、交換時は temp に元の先頭を退避します。

変数の値の変化
実行した処理postempdata
初期値1—{8, 3, 6, 2}
i = 22—{8, 3, 6, 2}
i = 32—{8, 3, 6, 2}
i = 44—{8, 3, 6, 2}
先頭を退避48{8, 3, 6, 2}
先頭を書き換え48{2, 3, 6, 2}
退避した値を戻す48{2, 3, 6, 8}

これは選択ソートの最初の1回です。残りの要素の並びはそのままです。

確認問題

配列 data の要素番号は1から始まります。処理後の data はどうなりますか？ 
整数型の配列: data ← {8, 3, 6, 2}
整数型: i, pos ← 1, temp

for (i を 2 から 4 まで 1 ずつ増やす)
  if (data[i] ＜ data[pos])
    pos ← i
  endif
endfor
temp ← data[1]
data[1] ← data[pos]
data[pos] ← temp
