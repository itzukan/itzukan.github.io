ループと条件分岐で合計する

配列を先頭からたどり、条件に合う値だけを足します。

🔁 4以上のときだけ足す

i は配列の要素番号です。条件が偽なら、sum は前の値のままです。

変数の値の変化
idata[i]4以上？処理後の sum
初期値——0
12いいえ0
25はい5
33いいえ5
48はい13

sum ← sum + data[i] の右側では、更新する前の sum を使います。

確認問題

配列 data の要素番号は1から始まります。次の処理が終わったとき、sum の値はいくつですか？ 
整数型の配列: data ← {2, 5, 3, 8}
整数型: i, sum ← 0

for (i を 1 から 4 まで 1 ずつ増やす)
  if (data[i] ≧ 4)
    sum ← sum + data[i]
  endif
endfor
