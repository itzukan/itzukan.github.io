条件に合う要素を数える

配列を走査し、条件を満たす回だけカウンタを増やします。

🔢 カウンタは一致したときだけ増える

一致しない周回では、count は前の値のままです。

変数の値の変化
idata[i]処理後の count
初期値—0
131
271
332
452
533

足すのは要素の値ではなく、1です。

確認問題

配列 data の要素番号は1から始まります。処理後の count はいくつですか？ 
整数型の配列: data ← {3, 7, 3, 5, 3}
整数型: i, count ← 0

for (i を 1 から 5 まで 1 ずつ増やす)
  if (data[i] = 3)
    count ← count + 1
  endif
endfor
