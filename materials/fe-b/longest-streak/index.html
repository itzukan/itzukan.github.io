連続した1の最長記録を求める

今続いている回数と、これまでの最長記録を別々に持ちます。

📊 連続が途切れたら run だけを0にする

1なら run を増やし、0なら run を0に戻してから、best と比較します。

best は最長記録なので、連続が途切れても小さくなりません。

確認問題

配列 data の要素番号は1から始まります。処理後の best はいくつですか？ 
整数型の配列: data ← {1, 1, 0, 1, 1, 1}
整数型: i, run ← 0, best ← 0

for (i を 1 から 6 まで 1 ずつ増やす)
  if (data[i] = 1)
    run ← run + 1
  else
    run ← 0
  endif
  if (run ＞ best)
    best ← run
  endif
endfor
