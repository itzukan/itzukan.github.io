配列を先頭からの累計に変える

書き換え済みの直前の要素を使い、先頭からの累計を作ります。

🧮 直前の累計を次の要素に足す

data[i - 1] は元の値ではなく、その時点の値です。

変数の値の変化
i足し算更新後の data
初期値—{3, 1, 4, 2}
21 ＋ 3{3, 4, 4, 2}
34 ＋ 4{3, 4, 8, 2}
42 ＋ 8{3, 4, 8, 10}

各要素が、元の配列で先頭からその位置まで足した値になります。

確認問題

配列 data の要素番号は1から始まります。処理後の data はどうなりますか？ 
整数型の配列: data ← {3, 1, 4, 2}
整数型: i

for (i を 2 から 4 まで 1 ずつ増やす)
  data[i] ← data[i] + data[i - 1]
endfor
