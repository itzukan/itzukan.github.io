基本情報技術者試験・科目B

条件に合う要素だけを別の配列へ写す

読む位置と書き込む位置を分けると、条件に合う値だけを詰めて並べられます。

📥 書き込んだときだけ next を進める

next は次に書き込む要素番号です。

変数の値の変化
i処理後の next処理後の out
初期値1{0, 0, 0, 0}
12{4, 0, 0, 0}
22{4, 0, 0, 0}
33{4, 9, 0, 0}
43{4, 9, 0, 0}

条件を満たさない周回は、out と next の両方が変わりません。

確認問題

2つの配列の要素番号は1から始まります。処理後の out はどうなりますか？ 
整数型の配列: data ← {4, 1, 9, 2}
整数型の配列: out ← {0, 0, 0, 0}
整数型: i, next ← 1

for (i を 1 から 4 まで 1 ずつ増やす)
  if (data[i] ≧ 4)
    out[next] ← data[i]
    next ← next + 1
  endif
endfor
