整列した2つの配列から小さい値を順に取る

2つの配列の未処理位置を別々に持ち、選んだ側だけを次に進めます。

🔀 比べるのは各配列の次の1個

left[i] と right[j] を比較し、小さい方をその回の out[k] に入れます。

変数の値の変化
k処理後の i処理後の jout
初期値11{0, 0, 0}
112{1, 0, 0}
222{1, 2, 0}
323{1, 2, 3}

この例のループは3回だけなので、両方に比較できる要素が残っている間に終わります。

確認問題

配列 left、right、out の要素番号は1から始まります。処理後の out はどうなりますか？ 
整数型の配列: left ← {2, 6, 9}
整数型の配列: right ← {1, 3, 7}
整数型の配列: out ← {0, 0, 0}
整数型: i ← 1, j ← 1, k

for (k を 1 から 3 まで 1 ずつ増やす)
  if (left[i] ＜ right[j])
    out[k] ← left[i]
    i ← i + 1
  else
    out[k] ← right[j]
    j ← j + 1
  endif
endfor
