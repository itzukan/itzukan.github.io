基本情報技術者試験・科目B

隣り合う値の増加を数える

1つ前の要素と比べて、大きくなった回数を数えます。

📈 比べるのは隣の2つ

i を2から始めるので、最初に比べるのは要素1と2です。

変数の値の変化
i前 → 今処理後の count
初期値—0
24 → 61
36 → 61
46 → 31
53 → 72

値の差の合計ではなく、増加した回数を求めています。

確認問題

配列 data の要素番号は1から始まります。処理後の count はいくつですか？ 
整数型の配列: data ← {4, 6, 6, 3, 7}
整数型: i, count ← 0

for (i を 2 から 5 まで 1 ずつ増やす)
  if (data[i] ＞ data[i - 1])
    count ← count + 1
  endif
endfor
