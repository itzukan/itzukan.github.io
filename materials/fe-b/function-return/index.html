関数の引数と戻り値を追う

同じ関数でも、呼び出すたびに受け取る値が変われば、通る分岐も変わります。

↩️ 呼び出しごとに x と戻り値を追う

呼び出し時に渡す値（引数）が x に入り、return の計算結果（戻り値）が呼び出し元に返ります。

変数の値の変化
呼び出しx通る分岐戻り値
adjust(3)33 ＜ 5：真5
adjust(8)88 ＜ 5：偽7

両方の戻り値がそろったら、result に 5 ＋ 7 ＝ 12 を代入します。

確認問題

関数 adjust を使って result ← adjust(3) + adjust(8) を実行します。result の値はいくつですか？ 
○整数型: adjust(整数型: x)
  if (x ＜ 5)
    return x + 2
  else
    return x - 1
  endif
