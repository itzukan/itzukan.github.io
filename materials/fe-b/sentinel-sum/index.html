目印の値まで配列を読み取る

配列の末尾まで読む代わりに、終了の目印に出会った時点で止めます。

🚩 0を見つけたら加算を止める

0が出た行では条件の確認だけを行い、本体は実行しません。

変数の値の変化
調べた値次の itotal
初期値10
data[1] = 323
data[2] = 639
data[3] = 0（終了）39

終了の目印を番兵と呼びます。0より後ろの8は合計に入りません。

確認問題

配列 data の要素番号は1から始まり、必ず0が1つ以上あります。処理後の total はいくつですか？ 
整数型の配列: data ← {3, 6, 0, 8}
整数型: i ← 1
整数型: total ← 0

while (data[i] ≠ 0)
  total ← total + data[i]
  i ← i + 1
endwhile
