累計の差から途中の範囲の合計を求める

先頭からの累計を並べておくと、欲しい区間より前の合計を引けます。

➖ 終点までの累計から、始点の手前までの累計を引く

prefix[i + 1] に、data の先頭から要素番号 i までの合計を保存します。

変数の値の変化
iこの回の足し算保存した値
初期値—prefix[1] = 0
10 ＋ 2prefix[2] = 2
22 ＋ 5prefix[3] = 7
37 ＋ 3prefix[4] = 10
410 ＋ 4prefix[5] = 14
ループ後14 − 2result = 12

prefix[2] を引くと、先頭の data[1] だけが合計から取り除かれます。

確認問題

配列 data と prefix の要素番号は1から始まります。処理後の result はいくつですか？ 
整数型の配列: data ← {2, 5, 3, 4}
整数型の配列: prefix ← {0, 0, 0, 0, 0}
整数型: i, result

for (i を 1 から 4 まで 1 ずつ増やす)
  prefix[i + 1] ← prefix[i] + data[i]
endfor
result ← prefix[5] - prefix[2]
