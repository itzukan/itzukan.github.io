配列の値を一時変数で入れ替える

配列の両端を入れ替えるときは、上書きされる前の値を別の変数に取っておきます。

📦 元の値を取っておいてから上書き

代入を1行ずつ実行し、変更された値を色付きで示しています。

変数の値の変化
実行した処理tempvalues の中身
初期値—{7, 4, 9}
① 先頭を退避7{7, 4, 9}
② 先頭に末尾の値7{9, 4, 9}
③ 末尾に退避した値7{9, 4, 7}

②が終わった時点で配列の中には7がありません。③で temp の7を使います。

確認問題

配列 values の要素番号は1から始まります。次の処理が終わったとき、配列の中身はどうなりますか？ 
整数型の配列: values ← {7, 4, 9}
整数型: temp

temp ← values[1]
values[1] ← values[3]
values[3] ← temp

  • 配列を逆順にコピーする 書く位置が先頭に近いほど、読む位置は元の配列の末尾に近くなります。
  • 配列の値を後ろからずらす 同じ配列を読み書きするので、まだ使う値を上書きしない順番が重要です。
  • 条件に合う要素だけを別の配列へ写す 読む位置と書き込む位置を分けると、条件に合う値だけを詰めて並べられます。
