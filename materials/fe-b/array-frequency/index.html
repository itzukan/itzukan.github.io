基本情報技術者試験・科目B

配列で値ごとの出現回数を数える

出てきた値を、そのまま回数を保存する場所の番号に使います。

🔢 値2が出たら freq[2] だけを増やす

freq[1]、freq[2]、freq[3] はそれぞれ値1、2、3の回数です。

変数の値の変化
ivaluefreq
初期値—{0, 0, 0}
12{0, 1, 0}
23{0, 1, 1}
32{0, 2, 1}
41{1, 2, 1}
53{1, 2, 2}
62{1, 3, 2}

各周回で、読んだ値に対応する回数だけを1増やします。

確認問題

配列 data と freq の要素番号は1から始まります。処理後の freq はどうなりますか？ 
整数型の配列: data ← {2, 3, 2, 1, 3, 2}
整数型の配列: freq ← {0, 0, 0}
整数型: i, value

for (i を 1 から 6 まで 1 ずつ増やす)
  value ← data[i]
  freq[value] ← freq[value] + 1
endfor
