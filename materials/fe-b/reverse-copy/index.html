配列を逆順にコピーする

書く位置が先頭に近いほど、読む位置は元の配列の末尾に近くなります。

🔃 i を増やしながら元の配列を後ろから読む

書き込みは out[1] から out[4] へ進みます。

変数の値の変化
書く i読む source処理後の out
初期値—{0, 0, 0, 0}
14{9, 0, 0, 0}
23{9, 5, 0, 0}
32{9, 5, 2, 0}
41{9, 5, 2, 7}

長さが4で要素番号が1始まりのため、逆向きの位置は 4 ＋ 1 − i です。

確認問題

2つの配列の要素番号は1から始まります。処理後の out はどうなりますか？ 
整数型の配列: data ← {7, 2, 5, 9}
整数型の配列: out ← {0, 0, 0, 0}
整数型: i, source

for (i を 1 から 4 まで 1 ずつ増やす)
  source ← 5 - i
  out[i] ← data[source]
endfor

  • 配列の値を一時変数で入れ替える 配列の両端を入れ替えるときは、上書きされる前の値を別の変数に取っておきます。
  • 配列の値を後ろからずらす 同じ配列を読み書きするので、まだ使う値を上書きしない順番が重要です。
  • 条件に合う要素だけを別の配列へ写す 読む位置と書き込む位置を分けると、条件に合う値だけを詰めて並べられます。
