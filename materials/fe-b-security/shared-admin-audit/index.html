基本情報技術者試験・科目B

管理画面の操作履歴から担当者を特定する

操作記録とアカウントの使い方を見比べて、誰が何をしたか追えるようにします。

🧾 アカウントと操作を結び付ける

  1. 👥
    現状を確認3人が共有アカウントを使うので、どの操作も同じ名前で記録される。
  2. 👤
    個別アカウントに変更担当者ごとに発行し、業務に必要な管理権限を割り当てる。
  3. 🔎
    操作ログで確認アカウント、操作、対象、時刻を照合し、変更の経緯を確認する。

個別アカウントの割り当て記録も管理し、誰が利用するアカウントか追えるようにします。

確認問題

今後、権限変更を誰が行ったか調べられるようにするには、どの対策が適切ですか？
  • 担当者3名が同じ管理アカウントを使っています。操作ログにはアカウント名、対象、操作時刻が残ります。
  • 先週、意図しない権限変更がありましたが、アカウント名だけでは担当者を特定できませんでした。
