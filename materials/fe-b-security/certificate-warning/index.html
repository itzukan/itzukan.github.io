基本情報技術者試験・科目B

証明書の警告が出たときの判断

ログイン画面を開いたとき、ブラウザが接続先を確認できない場合の対応を考えます。

⚠️ 警告 → 入力を止める → 正規の案内を確認

  1. 🌐
    警告に気付く証明書の名前が接続先と一致していない。
  2. 🛑
    ログインを止めるパスワードは入力せず、警告を回避して進まない。
  3. 📞
    担当窓口へ確認URLと警告内容を伝え、正規の案内に従う。

証明書の警告は、設定ミスでも表示されます。利用者だけで原因を決めつけず、担当者に確認します。

確認問題

社員がこの画面で取るべき対応はどれですか？
  • 社内ポータルへのリンクを開くと「この接続ではプライバシーが保護されません」という警告が出ました。
  • 警告には、証明書の名前がアクセス先の名前と一致しないと表示されています。個別の例外登録を認める社内案内はありません。
