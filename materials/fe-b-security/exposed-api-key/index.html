公開されたAPIキーの対応を決める

キーを含むファイルの公開後に、何を優先して止めるか考えます。

🔑 公開されたキーを使えなくする

  1. ⚠️
    外部に渡った可能性を考えるファイルを直しても、公開中にコピーされたキーは残り得る。
  2. 🔒
    元のキーを無効にする発行元で失効させ、必要なサービスを新しいキーに切り替える。
  3. 📋
    利用状況を確認漏えい期間の記録を調べ、対象サービスと影響範囲を確認する。

新しいキーは、サービスが承認した秘密情報の保管先で管理します。

確認問題

鍵の管理担当者が優先すべき対応はどれですか？
  • まだ有効な業務用APIキーが、公開リポジトリのファイルに誤って入りました。ファイルが公開されたのは30分前です。
  • 担当者には発行元でキーを無効にする権限があります。キーを使うサービスの切り替え手順もあります。
