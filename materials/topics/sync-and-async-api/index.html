同期APIと非同期APIの違い

大きな売上レポートを作るとき、呼び出し側がいつ結果を受け取るかを考えます。

図で仕組みを理解しよう

  • ⚡同期要求した呼び出しで結果を受け取る
  • 📨非同期受付とジョブIDを返す
  • 📄完了後に状態や結果を受け取る

ポイント

非同期のジョブは、ポーリング（定期確認）や通知で結果を受け取れます。HTTP 202は処理を受け付けた状態で、完了済みとは限りません。

確認問題

202が返った直後、レポートは必ずできている？
