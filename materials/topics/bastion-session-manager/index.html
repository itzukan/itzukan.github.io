クラウド・AWS

踏み台サーバーとAWS Session Manager

公開用の入口を増やさずに、社内の運用担当がサーバーを管理する方法を比べます。

図で仕組みを理解しよう

  • 🖥️踏み台経由専用の入口から管理先へ
  • ☁️Session ManagerAWSサービス経由で管理先へ
  • 📋IAM・接続要件・記録の設定を確認

ポイント

Session Managerには対象端末のエージェントとAWSサービスへの到達性、IAM権限が必要です。記録は設定や接続方式によります。SSHトンネルなどのセッション内容は記録できない場合があります。

確認問題

Session Managerを使えば必ず操作内容が全部残る？
