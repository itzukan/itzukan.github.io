API

API認証で呼び出し元を確認する

配送先を返すAPIが、誰からの要求か、どの注文を読めるかを判断します。

図で仕組みを理解しよう

  1. 📱アプリが認証情報を添える
  2. 🪪APIが有効性と呼び出し元を確認
  3. 🔒許された注文だけ返す

ポイント

APIキーは発行先のアプリ識別などに使い、OAuthのアクセストークンは付与された権限を示します。認証が通っても、対象の注文を読めるかは別に確認します。
