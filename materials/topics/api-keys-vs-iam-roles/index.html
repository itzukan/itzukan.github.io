APIキーとIAMロールの違い

外部の商品APIとAWSのS3に、それぞれどの認証情報を使うか考えます。

図で仕組みを理解しよう

  1. 🔑外部API発行されたAPIキー
  2. 🪪AWS上のアプリIAMロールの一時認証情報
  3. 🛡️漏えい時は無効化し記録を確認

ポイント

APIキーは提供元の仕組みで管理します。IAMロールはAWSの権限設定に用い、一時認証情報でアクセスできます。固定の認証情報が不要な環境ではSDKでロールを利用できます。
