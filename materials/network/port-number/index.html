ネットワーク入門

ポート番号とは？

同じサーバーでも、ポート番号でWeb閲覧とサーバー管理を区別できます。

図で仕組みを理解しよう

💻 PCWebを開く
→
🖥️ 接続先 192.0.2.10同じIPアドレス
→
🌐 TCP 443HTTPSの入口
💻 PCサーバーを管理する
→
🖥️ 接続先 192.0.2.10同じIPアドレス
→
🛠️ TCP 22SSHの入口

IPアドレスは接続先の機器、ポート番号は接続先のサービスを区別する手掛かりです。IPは説明用です。

❓ 疑問

同じサーバーにWebと管理の両方があるとき、どちらに接続するかはどう決まる？

💡 理由

Webの通信を保護するHTTPSは通常TCP 443、離れたサーバーを管理するSSHは通常TCP 22を使います。サービスの設定で番号は変更できます。TCPとUDPは通信のルールが異なり、同じ番号でも別の入口なので、番号だけでサービスは断定できません。

⌨️ 操作

Windows　PowerShellで、自分のPCが受け付けているTCP接続を表示します。

Windows PowerShell
netstat -ano -p tcp | Select-String LISTENING

Mac　ターミナルで、自分のPCが受け付けているTCP接続を表示します。

Mac ターミナル
lsof -nP -iTCP -sTCP:LISTEN

📋 結果を見てみよう（表示例）

Windows PowerShell
  TCP    127.0.0.1:3000    0.0.0.0:0    LISTENING    4212

左から通信方式、ローカルアドレス、相手先、状態、プロセスID。127.0.0.1:3000は、自分のPC内から接続できるTCP 3000の例です。

Mac ターミナル
COMMAND  PID  USER  FD  TYPE            DEVICE SIZE/OFF NODE NAME
node    4212  demo  20u IPv4 0x0000000000000000      0t0  TCP 127.0.0.1:3000 (LISTEN)

右端のTCPと127.0.0.1:3000を見ます。LISTENは接続を待っている状態です。

✅ 答え

IPアドレスに加え、TCPかUDPか、何番ポートかで通信先が分かれます。

まとめ

443と22はよく使われる番号です。どのアプリがそのポートで接続を待っているかを知りたいときは、ポート番号と同じ行を見ます。上の表示例では、Windowsなら右端のプロセスID 4212 をタスク マネージャーの「詳細」で探し、Macなら先頭の COMMAND 欄を見ます。Macの例では、node がポート 3000 で待ち受けています。
