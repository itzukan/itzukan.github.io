リモートデスクトップとは？VPNとの違い

自宅PCから会社PCを操作したとき、どちらで処理が行われるかを図で見ます。

図で仕組みを理解しよう

💻 自宅PC入力する・画面を見る
① 操作を送る→
←② 画面が返る
🖥️ 会社PCアプリを実行する

自宅PCから会社PCへ操作を送り、会社PCから自宅PCへ処理後の画面が返ります。会社でVPNが必要な場合は、その経路を通ります。

❓ 疑問

自宅PCに会社のアプリが表示されたとき、アプリはどちらで動く？

💡 理由

VPNは社内ネットワークへつながる経路を作ります。リモートデスクトップは接続先のPCを操作する仕組みです。入力と表示を自宅PCが担い、業務アプリの処理は会社PCで行われます。たとえば会社が認めたVPNで社内につなぎ、そのあと会社PCをリモート操作します。

⌨️ 操作

Windows　Windowsで Win + R を押し、次の文字を入れてEnter。接続画面を開いたら、入力欄を確認して閉じます。

ファイル名を指定して実行（Win + R）
mstsc

📋 結果を見てみよう（表示例）

リモート デスクトップ接続
コンピューター: [                    ]
                         [ 接続 ]

コンピューター欄は、会社から案内された接続先名などを指定する場所です。画面の模式例です。

✅ 答え

アプリは会社PCで動きます。VPNで社内へ接続することと、会社PCをリモートで操作することは役割が別です。

まとめ

練習は接続画面を見るところまでです。実際に使うときは、接続方法、利用権限、接続先を会社のルールで確認します。
