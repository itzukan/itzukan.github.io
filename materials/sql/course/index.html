MISSION 11 · LEFT JOIN

一度も購入していないお客様を探そう

鈴木さん｜マーケティング
「会員登録したけど一度も買っていないお客様を調べてもらえる？」
SELECT c.name
FROM customers AS c
LEFT JOIN orders AS o
  ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
